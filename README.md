# 石大查询 · AstrBot 插件
不觉得图书馆预约界面太不直观还不好操作吗!

过于社恐不想坐别人旁边怎么办!

不想去图书馆找空教室还得满楼找很麻烦吗!

所以我拜托尊敬的**DSH**大人写了这个!（顺便把课表也做进来了）

中国石油大学（华东）的聊天机器人（astrbot）查询插件：**空教室** · **图书馆座位** · **课表**。
> 个人开发项目，与学校官方无关。只做查询，不做自动预约/抢座。

> 本项目完全由 **DSH（DeepSeek Harness）** 开发完成。

## 功能

| 命令 | 说明 | 需要登录 |
|---|---|---|
| `/空教室 [楼] [节次]` | 查哪里能自习 | ❌ |
| `/空教室 附近 南教305 [节次]` | 附近教室哪些空着/有课（带课程名） | ❌ |
| `/课表 [今天&#124;明天&#124;周三&#124;第8周]` | 课表查询 | ✅ |
| `/课表 推送 开&#124;关&#124;状态` | 每日定时推送明天课表 | ✅ |
| `/图书馆` | 实时空座 + 开馆时间 | ❌ |
| `/图书馆 东馆` / `总馆` | 各房间空位（可加时间段） | ✅ |
| `/图书馆 列表` | 房间 id 列表 | ✅ |
| `/图书馆 地图 2 [日期] [时间段]` | 座位示意图（图片，标座位号） | ✅ |
| `/图书馆 空位 2 [日期] [时间段]` | 找周围没人的座位 | ✅ |
| `/图书馆 拉黑 2 007` | 座位黑名单 | ❌ |
| `/图书馆 黑名单` / `取消拉黑` | 查看/移除黑名单 | ❌ |
| `/图书馆 我的` | 我的预约 | ✅ |
| `/石大帮助` | 命令列表 | ❌ |
| `/upc` | Telegram 菜单入口（完整帮助） | ❌ |
| `/upckb` / `/upckj` / `/upcts` | 课表 / 空教室 / 图书馆 快捷入口 | 视功能而定 |

### Telegram 菜单
（至于为什么选择tg，因为腾子会把我的小号踹下来，discord搞机器人太麻烦！）

Telegram 的 Bot 菜单只能平铺命令、不支持中文命令名，所以插件提供 4 个 ASCII 入口，
配合自定义菜单（9 条）使用：

```
/upc     石大查询：完整帮助
/upckb   课表：/upckb 今天 /upckb 第8周
/upckj   空教室：/upckj 南教楼 3-4
/upcts   图书馆：/upcts 东馆 /upcts 地图 2
```

### 按时间段筛选

图书馆座位支持指定时间段，例如：

```
/图书馆 地图 2 明天 08:00-10:00
/图书馆 空位 2 14:00-16:00
/图书馆 东馆 08:00-10:00
```

时间写法：`08:00-10:00`、`8-10`、`14:00~16:00` 都可以；不写就是「当前时刻」。

### 座位示意图

![座位示意图](docs/preview_map.png)

- 绿=空座，红=有人，深黑=你拉黑的座位，浅灰=不可用，蓝=桌子/隔断，白=走廊
- 每个座位标注 3 位座位号（程序内置点阵字体，不依赖字体文件）
- （或许有人好奇为什么要做座位拉黑，因为经常会坐到有太阳光直射眼睛或者地板反射太阳直射眼睛的座位，很绝望）

## 安装

### 方式一：插件市场

在 AstrBot WebUI → 插件 → 插件市场 搜索「石大查询」安装。

### 方式二：手动

```bash
cd AstrBot/data/plugins
git clone https://github.com/kujochisaki3378/astrbot_plugin_upc
```

然后 WebUI → 插件 → 启用。

## 配置

WebUI → 插件 → 石大查询 → 配置：

| 配置项 | 说明 |
|---|---|
| `username` | 学号 |
| `password` | 数字石大密码（不是图书馆单独密码） |
| `auto_login` | token 失效时自动登录，默认开启 |

- 图书馆登录态存在 `~/.astrbot_plugin_upc/token`
- 座位黑名单存在 `~/.astrbot_plugin_upc/blacklist.json`
- 密码以**明文**保存在 AstrBot 的插件配置文件中；不想存就留空，改用 `/图书馆` 的免登录功能

## 数据来源
从微信企业号找的网址
- 空教室：`app.upc.edu.cn/freeclass`（公开接口，无需登录）
- 图书馆：`libspace.upc.edu.cn/libseat`（空座统计公开，其余需 token）
- token 通过 CAS 统一认证自动获取；座位图坐标 `key = row*1000 + col`
